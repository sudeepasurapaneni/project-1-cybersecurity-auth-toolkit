# Secure Authentication Toolkit

A Python-based cybersecurity project that demonstrates password security, secure authentication practices, and the detection of suspicious login activities.

## Features

- **Password Strength Checker:** Evaluates password strength based on length, character variety, and common-password checks.
- **Login Lockout Simulator:** Demonstrates account lockout after repeated failed login attempts.
- **Secure Password Generator:** Generates passwords using configurable character types.
- **Brute Force Attack Detection:** Identifies suspicious IP addresses based on repeated failed login attempts.
- **Password Guessing Detection:** Detects accounts targeted by multiple failed password attempts.

## Technologies Used

- Python
- Regular Expressions
- Python Standard Library
- Command-Line Interface (CLI)

## Project Purpose

The purpose of this project is to demonstrate fundamental cybersecurity concepts, including password security, authentication protection, and suspicious login activity detection.

## Disclaimer

This project is intended for educational and demonstration purposes only.
